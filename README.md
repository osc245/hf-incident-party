# Incident Party

A whimsical costume guide to the documented agents and supporting cast of the 2026 OpenAI–Hugging Face incident.

Built with Bun and React. Bun provides the development server, JSX and CSS bundling, hot reloading, dependency management, and production build.

## Development

```bash
bun install
bun run dev
```

Open the URL printed by Bun.

## Production build

```bash
bun run build
bun run preview
```

The static production output is written to `dist`.
